# YouTube 非中文视频端到端验收（2026-08-02）

使用用户明确授权下载的一条公开 TED 英语视频，完成以下实测链路：

1. 通过既有下载入口保存完整 MP4，并保留平台 `zh-CN` VTT。
2. 探测 AV1/Opus 流、全片事件区间、事件帧和自适应时间覆盖帧。
3. 由本地 `large-v3-turbo` 写出 221 段英文原始时间码 ASR 与英文外置 SRT。
4. 由现有本地 Qwen 翻译器尝试完整编号翻译；实际只返回 43/221 段，完整性门正确标为 `partial`。
5. 双语 SRT 保留全部英文，仅为已验证的 43 段附加简体中文；不伪造未翻译段。
6. 按视觉变化导出 4 个派生候选片，并为每条实际生成重置到 00:00:00 的原文 SRT。

## 结论

- 下载、原字幕保留、全片 ASR、原文 SRT、候选片导出、候选 SRT 时间码归零均通过真实运行验证。
- 长视频的单批本地翻译目前不能通过生产验收：受限于单次输出，只有 43/221 段完成；抽样还发现术语与平台译文不一致。
- 后续实现应把翻译按时间码段分批、每批执行编号完整性校验，并抽样与音频及平台字幕交叉复核后，才交付双语字幕。
- VTT 写出、FFmpeg 内封和烧录字幕不在本次验收范围内。
